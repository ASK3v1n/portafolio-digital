Reflexión Holística

Autoevaluación crítica sobre el proceso de aprendizaje, retos superados y metas alcanzadas.

Desafíos Enfrentados

Durante el desarrollo del curso, uno de los mayores retos fue la curva de aprendizaje al integrar de forma síncrona el manejo de bases de datos relacionales y no relacionales con tecnologías móviles. Asimismo, la gestión del tiempo para coordinar el desarrollo colaborativo en Git, resolver conflictos de fusión (merge conflicts) y asegurar la estabilidad de los entornos locales de desarrollo requirió un esfuerzo analítico adicional.

Logros Obtenidos

Se logró consolidar la arquitectura del sistema recolector de basura (MiniSys) de manera exitosa, cumpliendo con los estándares requeridos de persistencia y modularidad. Otro logro significativo fue dominar el flujo de trabajo profesional en repositorios de Git y el uso avanzado de hojas de estilo eficientes, lo que permitió optimizar el tiempo de respuesta visual de las interfaces diseñadas.

Lecciones Aprendidas

La experiencia técnica reafirmó que el desarrollo de software no se limita a escribir código, sino a planificar arquitecturas escalables y limpias. Se comprendió la importancia crítica de la documentación técnica precisa y de la comunicación asertiva dentro de un equipo de ingeniería. Estas habilidades blandas y duras forman una base sólida para afrontar proyectos de mayor envergadura en el ámbito profesional.
